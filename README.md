# Café BPX

Projeto estático do **Café BPX**, pronto para deploy no Vercel.

## Páginas
- `index.html` — visualização pública do cardápio
- `login.html` — login administrativo
- `admin.html` — controle de disponibilidade

## Acesso administrativo (demo)
- **Usuário:** `admin`
- **Senha:** `admin`

## Recursos
- layout responsivo com foco na versão mobile aprovada
- persistência local com `localStorage`
- cards de cafés com status disponível/indisponível
- painel administrativo com alternância por switch

## Publicação
Projeto estático, sem etapa de build.
